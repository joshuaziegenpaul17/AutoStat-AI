# **App Name**: AutoStat AI

## Core Features:

- Intelligent CSV Processing: Robust CSV file upload with automated data validation, cleaning suggestions, and storage in a PostgreSQL database via Prisma.
- Automated Statistical Engine: Calculates descriptive statistics (mean, variance, quartiles) and correlation matrices automatically upon dataset ingest.
- Advanced Hypothesis Testing Suite: Configurable interface to run T-Tests, ANOVA, and Linear Regression models against selected data columns.
- Generative Narrative Analyst: Uses AI as a tool to generate professional textual interpretations of statistical results, identifying trends and significance for reports.
- Dynamic Analytics Dashboard: Interactive data visualization gallery using Recharts to render Histograms, Boxplots, and Heatmaps.
- Persistence & Analysis History: Save previous analyses and datasets to the user's dashboard for quick access and cross-comparison.
- Exportable PDF Reporting: Generates a cohesive, professional statistical report exportable to PDF including visuals and AI interpretations.

## Style Guidelines:

- Primary color: Vibrant Tech Indigo (#6652f5) for a professional and data-driven identity.
- Background color: Deep Charcoal-Indigo (#131217) providing a dark, high-contrast environment suitable for glassmorphism.
- Accent color: Celestial Azure (#85b0ff) for distinct highlights, hover states, and key data points.
- Font pairing: 'Space Grotesk' for technical, bold headlines and 'Inter' for clear, highly readable data-heavy body text.
- A dashboard-first layout utilizing Glassmorphism—frosted glass panels with subtle border glows and blurred backdrops.
- Thin-line SVG icons representing statistical concepts like curves, distribution plots, and connectivity.
- Micro-interactions for card hovering and progressive entry animations for charts as they compute and render.
