## 📌 Overview

**AutoStat AI** is a modern, end-to-end analytics platform that transforms raw Excel datasets into actionable business intelligence — instantly.

Upload your data and receive professional-grade statistical analysis, interactive visualizations, predictive forecasts, AI-written executive summaries, and a downloadable PDF report — all in one seamless workflow. Built for analysts, researchers, data scientists, and business leaders who need fast, reliable insights without writing a single line of code.

## ✨ Core Features

### 📊 Automated Statistical Profiling
Instantly compute mean, median, mode, variance, standard deviation, range, skewness, kurtosis, and full summary statistics across all numeric columns.

### 📈 Interactive Visualizations
Generate dynamic histograms, pie charts, distribution plots, trend lines, correlation heatmaps, and category comparisons — all rendered interactively in-browser.

### 🔍 Data Quality Assessment
Automatically surface missing values, outliers, structural inconsistencies, and data integrity issues before analysis begins.

### 🤖 AI Executive Intelligence
Powered by **Groq + Llama 3.3 70B** — generate C-suite-ready executive summaries, strategic recommendations, opportunity analysis, risk identification, and business insights tailored to your data.

### 📉 Predictive Forecasting
Run trend forecasting, growth projections, sequential analysis, and historical pattern recognition on time-series or structured datasets.

### 📄 PDF Report Export
Download a professional report containing all statistical findings, charts, forecast outputs, AI insights, and recommendations in a single shareable document.

### 🔒 Security & Compliance
Includes privacy policy, terms of service, security disclosures, and professional disclaimers built into the platform.

## ⚙️ Installation

**Clone the repository**

```bash
git clone https://github.com/joshuaziegenpaul17/AutoStat-AI.git
cd AutoStat-AI
```

**Install dependencies**

```bash
npm install
```

**Configure environment**

Create a `.env.local` file in the root directory and add:

```env
GROQ_API_KEY=your_api_key_here
```

Get a free Groq API key at [console.groq.com](https://console.groq.com)

**Start the development server**

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) in your browser.
